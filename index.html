// 01 · contexto

¿Por qué vamos a hacer esto?

Antes de escribir código, necesitas entender el problema real que vas a resolver.

El año es 1994. En la Universidad de Wisconsin, la doctora Olvi Mangasarian y su equipo tienen un problema: los médicos tardan días en analizar una biopsia de tumor de mama. A veces se equivocan. A veces llegan tarde.

Tienen datos de 569 biopsias reales — 30 mediciones de cada tumor: radio, textura, perímetro, área, suavidad... Cada una está etiquetada como maligna (cancerosa) o benigna (no cancerosa).

La pregunta es: ¿puede una computadora aprender a distinguirlas automáticamente?

Hoy tú vas a ser el científico de datos. Vas a construir ese modelo. Y al final, verás cuántos tumores acierta y cuántos falla.

→ Dataset real: Breast Cancer Wisconsin · UCI Machine Learning Repository · 1994

El objetivo
Clasificar tumores
Dado un conjunto de mediciones de un tumor, predecir si es maligno (0) o benigno (1).
Lo que tenemos
569 muestras reales
30 características numéricas por muestra. 212 malignos y 357 benignos. Ya vienen en sklearn.
El algoritmo
Random Forest
Un "bosque" de árboles de decisión que votan juntos. Robusto, interpretable y perfecto para aprender hiperparámetros.
⚠️
Importante: En este problema un Falso Negativo (decirle a un paciente que su tumor es benigno cuando es maligno) es mucho más grave que un Falso Positivo. Esto va a influir en qué métricas debemos priorizar.

RandomForestClassifier(n_estimators=100)

Las 4 métricas que vas a calcular

Accuracy — Exactitud
¿Cuántos acerté en total?
La más simple. Cuidado: con datos desbalanceados puede mentir.
(TP + TN) / (TP + TN + FP + FN)
Precision — Precisión
De los que dije positivo, ¿cuántos lo eran?
Importante cuando los Falsos Positivos son costosos.
TP / (TP + FP)
Recall — Sensibilidad
De todos los positivos reales, ¿cuántos encontré?
Crítico aquí: no queremos perder tumores malignos (FN).
TP / (TP + FN)
F1-Score
Media armónica de Precision y Recall
El mejor indicador único. Penaliza cuando uno de los dos es bajo.
2 × (P × R) / (P + R)

TP y TN
Aciertos. El modelo predijo bien. Más de estos = mejor.
FN — El más peligroso aquí
Dijo "benigno" pero era maligno. En cáncer esto puede costar una vida. Queremos minimizar los FN.
FP
Dijo "maligno" pero era benigno. Genera ansiedad innecesaria pero es menos grave que FN.

PASO 4

Crear el modelo con hiperparámetros

Aquí configuras las "perillas" del modelo. Este es el corazón del submódulo.

Los hiperparámetros que vas a controlar:

Hiperparámetro ¿Qué controla exactamente? Valor base Rango recomendado Bajo → efecto Alto → efecto
n_estimators Cuántos árboles forman el "bosque" 10 10 – 500 rápido / impreciso preciso / lento
max_depth Profundidad máxima de cada árbol 3 1 – 20 / None subajuste sobreajuste
min_samples_split Mínimo de muestras para dividir un nodo 2 2 – 20 árbol complejo más regularizado
min_samples_leaf Mínimo de muestras en una hoja final 1 1 – 15 memoriza datos generaliza mejor
random_state Semilla de aleatoriedad interna 42 cualquier int Solo afecta reproducibilidad, no rendimiento
mi_modelo.py — agrega después del Paso 3
# ── PASO 4: CREAR EL MODELO ───────────────────────────────────────── # # RandomForestClassifier = "bosque de árboles de decisión" # Cada árbol vota y la clase con más votos gana # # ════════════════════════════════════════════════════════════ # ✏ ZONA DE CONFIGURACIÓN — modifica estos valores # ════════════════════════════════════════════════════════════ N_ESTIMATORS = 10 # número de árboles en el bosque MAX_DEPTH = 3 # profundidad máxima de cada árbol (None = sin límite) MIN_SAMPLES_SPL = 2 # mín. de muestras para dividir un nodo MIN_SAMPLES_LF = 1 # mín. de muestras que debe tener una hoja # ════════════════════════════════════════════════════════════ modelo = RandomForestClassifier( n_estimators = N_ESTIMATORS, max_depth = MAX_DEPTH, min_samples_split = MIN_SAMPLES_SPL, min_samples_leaf = MIN_SAMPLES_LF, random_state = 42 # reproducibilidad ) print("=" * 60) print(" MODELO CREADO — Random Forest Classifier") print("=" * 60) print(f" n_estimators : {N_ESTIMATORS} (árboles)") print(f" max_depth : {MAX_DEPTH}") print(f" min_samples_split : {MIN_SAMPLES_SPL}") print(f" min_samples_leaf : {MIN_SAMPLES_LF}") print() print(" ⚙ El modelo está CREADO pero aún NO entrenado.") print(" El entrenamiento ocurre en el Paso 5.") print("\n✅ Paso 4 completado — modelo configurado")

# ── PASO 5: ENTRENAR EL MODELO ────────────────────────────────────── # # .fit(X_train, y_train) = el modelo estudia los datos de entrenamiento # # Lo que ocurre internamente: # 1. Construye N_ESTIMATORS árboles de decisión # 2. Cada árbol usa una muestra aleatoria de los datos (bagging) # 3. En cada nodo, elige la mejor característica para dividir # 4. Los árboles quedan guardados en memoria como PARÁMETROS del modelo print(" Entrenando el modelo... ", end="", flush=True) modelo.fit(X_train, y_train) # ← TODO el entrenamiento en una línea print("listo ✓") print() # Curiosidad: ¿cuántos árboles se crearon realmente? n_arboles_reales = len(modelo.estimators_) print(f" Árboles creados : {n_arboles_reales}") print(f" Clases aprendidas : {list(modelo.classes_)} → 0=maligno, 1=benigno") print(f" Características usadas : {modelo.n_features_in_}") # El árbol #0 (el primero) — ver su profundidad real print(f" Profundidad árbol #1 : {modelo.estimators_[0].get_depth()}") print("\n✅ Paso 5 completado — modelo entrenado") print(" Ahora el modelo conoce los patrones de 455 biopsias.")
.fit()
El método que entrena. Recibe X (features) e y (etiquetas). Modifica el modelo internamente.
Parámetros aprendidos
Después del .fit(), el modelo guarda los árboles en modelo.estimators_. Los puedes inspeccionar.
Tiempo de entrenamiento
Con 10 árboles es instantáneo. Con 500 puede tardar 1-2 segundos. El número después del punto es un parámetro.
